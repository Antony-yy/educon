# EDUCON 🎓

Sistema acadêmico desenvolvido como projeto de estudo para facilitar a gestão escolar.

## 📌 Sobre o projeto

O EDUCON tem como objetivo organizar informações acadêmicas e apoiar atividades relacionadas à gestão de turmas e ao acompanhamento escolar.

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript

## ✨ Funcionalidades

- Gestão de informações acadêmicas.
- Organização de turmas.
- Interface para apoiar atividades escolares.

> As funcionalidades acima devem ser ajustadas de acordo com o que está realmente implementado no projeto.

## 🚀 Como executar

1. Clone este repositório.
2. Abra a pasta do projeto no computador.
3. Siga as instruções de execução definidas pelo projeto.

## 🎯 Objetivo acadêmico

Projeto desenvolvido para praticar programação, organização de código, controle de versão com Git e colaboração pelo GitHub.
